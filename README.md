# AliClin Agenda

Agenda web da AliClin com:
- Consultório 1, Consultório 2 e Consultório 3
- Cadastro, visualização, remarcação e cancelamento de agendamentos
- Filtros por profissional e sala
- Profissionais da clínica já cadastrados na interface

## Publicação
Este pacote pode ser enviado diretamente para a raiz do repositório GitHub conectado à Vercel.
O arquivo inicial é `index.html`.

## Banco e login
Esta versão inicial usa armazenamento local do navegador para permitir a publicação imediata.
A integração compartilhada com Supabase/login deve ser ativada em uma etapa posterior, usando
as credenciais públicas do projeto Supabase sem publicar senhas ou chaves secretas no GitHub.
